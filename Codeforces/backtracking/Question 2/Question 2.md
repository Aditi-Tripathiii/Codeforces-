B. Climb Stairs - II
time limit per test
1 second
memory limit per test
256 megabytes

You are standing at the bottom of a staircase with N steps.

At each move, you can jump any number of steps from 1 to K (inclusive).

Your task is to print all possible ways to reach exactly step N.

Each path should be represented as a sequence of jumps.
Input

    N (1≤N≤15) — number of stairs
    K (1≤K≤N) — maximum jump allowed 

Output

Print all valid paths, one per line.

Each path should contain space-separated jumps.

Paths must be printed in lexicographical order.
Examples
Input
Copy

3 3

Output
Copy

1 1 1
1 2
2 1
3

Input
Copy

4 3

Output
Copy

1 1 1 1
1 1 2
1 2 1
1 3
2 1 1
2  2
3 1
