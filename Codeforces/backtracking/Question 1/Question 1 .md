A. Climb Stairs - I
time limit per test
1 second
memory limit per test
256 megabytes

You are standing at the bottom of a staircase with N steps.

At each move, you can either:

    Jump 1 step
    Jump 2 steps 

Your task is to print all possible ways to reach exactly step N.

Each path should be represented as a sequence of jumps using numbers 1 and 2.
Input

A single integer N (1≤N≤20) — number of stairs.
Output

Print all valid paths, one per line.

Each path should contain space-separated jumps.

Print paths in lexicographical order.
Examples
Input
Copy

3

Output
Copy

1 1 1
1 2
2 1

Input
Copy

2

Output
Copy

1 1
 2
